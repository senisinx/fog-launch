# Fog Launch

Startet Dead by Daylight (Epic) mit mehreren Epic-Konten aus einer Installation: Profile, Startfolgen, Grafik-
und Eingabe-Presets, Fensterpositionen. Windows 10/11, Fenster mit Tkinter, Epic-Teil über
[Legendary](https://github.com/legendary-gl/legendary). Aufbau der Dateien: Tabelle „Layout“ in `README.md`.

## Setup und Prüfen

```bash
python -m fog_launch
python -m unittest discover -s tests -t .
python -m pyflakes fog_launch tests get_legendary.py fog_launch.pyw
```

Nur Standardbibliothek (Python ≥ 3.11), keine Pakete zur Laufzeit. CI (`.github/workflows/tests.yml`): pyflakes
und die Tests unter Windows und Linux auf 3.11 (ältestes laut README), 3.12 (baut die exe) und 3.13; der
Fenstertest `tests/test_gui.py` läuft unter Linux mit `xvfb-run` und wird ohne Tk oder Bildschirm übersprungen.
Neue oder geänderte englische Texte brauchen ihre deutsche Fassung in `fog_launch/i18n.py` (`tests/test_texts.py`).

## Regeln

- **Netz nur auf Klick.** Online geht nur `fog_launch/update.py`, und nur nach „Update Fog Launch…“ oder
  „Download Legendary“. Nichts im Hintergrund, keine Telemetrie. Legendary selbst spricht mit Epic.
- **Updates nur aus Releases, immer geprüft:** die exe gegen `SHA256SUMS.txt`, ZIP-Kopien über
  `FogLaunch-source.zip` gegen dieselbe Datei, git-Kopien per Fast-Forward auf das Release-Tag. Fehlt eine
  Datei oder Prüfsumme, wird abgelehnt, nicht ohne Prüfung installiert. Legendary nur mit fester SHA-256.
- Downloads: in Stücken (`update.fetch`), mit Grenze `MAX_DOWNLOAD`, Abbruch über `runner.cancel`, zwei
  Wiederholungen nur bei Verbindungs- und Serverfehlern.
- Lange Arbeit (Legendary, Downloads, PowerShell) läuft über `App.work()`, nie im Fenster-Thread.
- Ungespeicherte Änderungen in den Preset-Tabs überleben `refresh()` (`PresetTab.dirty`).
- Dateien atomar schreiben (`store.write_bytes_atomic`); Pfade aus ZIPs gegen Traversal prüfen.
- Release: `__version__` in `fog_launch/__init__.py` erhöhen, README anpassen; das Release veröffentlicht nur der
  Nutzer (Ablauf in `README.md`). Actions per Commit-SHA gepinnt (Tag als Kommentar).
